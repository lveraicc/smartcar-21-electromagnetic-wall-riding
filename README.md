# 第 21 届全国大学生智能汽车竞赛电磁组：飞檐走壁

本仓库整理了 **STC32G 电磁组飞檐走壁** 参赛车的嵌入式控制代码。工程基于逐飞科技 STC32G 开源库，使用 Keil C251 编译。代码主要完成四路电感循迹、IMU 姿态融合、编码器测速、双电机闭环控制、特殊路段判断以及吸附风扇控制。

> 这是参赛版本的归档。参数与状态机依赖实际车模、赛道和传感器安装位置，直接烧录到不同结构的小车上不保证可运行。

## 主要功能

- **10 ms 定时控制**：TIM1 周期中断读取传感器、编码器与 IMU，并执行车辆控制。
- **电磁循迹**：四路 ADC 采集、5 点中值滤波、归一化和加权偏差计算。
- **姿态估计**：IMU660RB 加速度计与陀螺仪数据经卡尔曼滤波输出 pitch、roll 和相对 yaw。
- **电机控制**：左右轮增量式速度 PI，叠加位置式 PD 转向环，驱动 DRV8701。
- **特殊路段辅助**：根据电感归一化值进入分阶段状态机，在限定时间内使用固定转向量。
- **安全停车**：四路电感都低于阈值时清空 PID 状态并立即停车。
- **吸附风扇**：PWMB_CH3 输出 PWM；检测到按键后从 3000 提升至 4500，并进入可运行状态。
- **调试数据**：通过蓝牙串口周期输出四路 ADC 原始值和左右编码器计数。

## 控制流程

```text
四路电磁 ADC ──中值滤波/归一化──> 循迹偏差
                                      │
                                      ▼
                                 转向 PD 控制
                                      │
编码器测速 ───────────────────> 左右轮速度 PI
                                      │
                                      ▼
                                DRV8701 双电机

IMU660RB ──卡尔曼滤波──> pitch/roll/yaw
                              │
                              └──> 特殊路段与坡面判断数据
```

每个 10 ms 控制周期的主要步骤如下：

1. 读取四路电感，采样五次后取中值，再按各通道标定范围归一化。
2. 读取并清零左右编码器计数。
3. 更新 IMU660RB 和卡尔曼姿态滤波器。
4. 计算电磁偏差，并运行特殊路段状态机。
5. 若四路归一化值均不大于 5，执行安全停车。
6. 按键启动后，转向 PD 输出与速度 PI 闭环输出共同控制左右轮。

## 硬件平台

主要配置如下，完整引脚表见 [docs/HARDWARE.md](docs/HARDWARE.md)。

| 模块 | 型号/接口 |
|---|---|
| 主控 | STC32G / AI32G12K128 |
| 姿态传感器 | IMU660RB |
| 电磁传感器 | 4 路模拟电感，12 位 ADC |

| 吸附风扇 | PWMB_CH3，10 kHz PWM |

## 编译

1. 安装 Keil µVision 5 和 **C251 编译器**。
2. 打开 `Project/mdk/seekfree.uvproj`。
3. 选择 `STC32G` 目标，执行 **Rebuild**。
4. 编译产物默认写入 `Project/mdk/out_file/`，该目录已被 Git 忽略。

工程使用相对路径引用 `Libraries`，请保持当前目录层级。Windows 文件系统不区分路径大小写，因此工程中的部分 `libraries` 路径仍可正常找到 `Libraries` 文件夹。部分第三方源码使用 GBK 编码；如果注释显示乱码，请将编辑器编码切换为 GBK/GB2312。

## 启动与调试

- 上电后风扇先以 2000 的占空比目标值启动。
- 按下 `P7.3` 按键后，风扇依次输出 3000、延时 1 秒、4500，随后置位启动标志并允许车辆控制。
- 蓝牙串口默认每轮输出：

  ```text
  :adc3,adc2,adc1,adc0,encoder_left,encoder_right
  ```

- `LED1` 连接 `P5.2`；蜂鸣器驱动位于 `BUZZER.*`，但当前主流程未调用。

## 参数与当前启用状态

常用参数集中在以下位置：

- 基础速度与 PID 参数：`Project/user/main.c`
- 电感标定范围、滤波长度与偏差权重：`Project/mdk/INDUCTOR.h`
- 电机、风扇引脚和 PWM 频率：`Project/mdk/DRV8701.h`、`DRV8701.c`
- 卡尔曼噪声参数：`Project/mdk/KALMAN.c`

归档时需要注意：

- `surface_mode_update()` 已实现但调用被注释，当前版本使用 `speed_pid_set(2)` 的参数。
- `TEST_DISABLE_NO_LINE_STOP` 仅在 `main.c` 中定义，当前代码没有用它关闭停车判断。
- `TOF.*` 和 `BUZZER.*` 保留在工程中，但未接入当前主控制流程。
- 原工程的编译日志、IDE 用户状态和中间文件已从仓库中排除。
